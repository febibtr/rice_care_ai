# RiceAi Frontend

Project awal frontend RiceAi menggunakan React + Vite + Bootstrap.

## Fitur awal
- Landing Page
- Login
- Register
- Reset Password

## Cara menjalankan

```bash
npm install
npm run dev
```

Lalu buka browser ke:

```bash
http://localhost:3000
```

## Struktur folder

```text
src/
  assets/
  components/
  pages/
  App.jsx
  main.jsx
  style.css
```
